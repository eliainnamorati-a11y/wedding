## 2. BRANDING, TYPOGRAPHY & COLOR PALETTE

### Design Aesthetic
* **Mood:** Haute couture Italian editorial, timeless Old-World Mediterranean elegance, romantic letterpress stationery, fine-art watercolor motifs.
* **Logo / Monogram:** Intertwined calligraphy **E&D** monogram rendered in antique gold gradient.
* **Iconography:** Minimalist gold heart emblem (`heart.svg`), architectural line-art sketches of Roman venues and Swiss Alpine villa.

### Typography Hierarchy
* **Script / Display Calligraphy:**
  * *Primary:* **Mozart Script Thin** (`MozartScript-Thin.ttf`)
  * *Web/Fallback:* **Great Vibes** (Google Fonts)
  * *Usage:* Couple's names ("Elia & Daniel"), main headlines, formal salutations ("Dear Fausto,").
* **Editorial Serif:**
  * *Font:* **Cormorant Garamond** (Google Fonts — weights 300, 400, 500, 600, italics)
  * *Usage:* Section titles, prose invitations, dates, vows, venue titles.
* **Body & UI Sans-Serif:**
  * *Font:* **Inter** (Google Fonts — weights 200, 300, 400, 500, 600)
  * *Usage:* Timelines, hours, addresses, buttons, form inputs, lookbook captions.

## 6. RSVP & DATA ARCHITECTURE

### Form Data Fields (Villa Honegg — Civil)
* `guestNum`: 1 Person / 2 Personen
* `guestName` (Required): Name 1. Gast
* `menuPreference1` (Required): Fleisch / Fisch / Vegetarisch
* `guestDiet1` (Optional): Allergies Gast 1
* `guestName2` (Required when 2 Pax): Name 2. Gast
* `menuPreference2` (Required when 2 Pax): Fleisch / Fisch / Vegetarisch
* `guestDiet2` (Optional): Allergies Gast 2
* `guestNote` (Optional): Personal message to Elia & Daniel

### Form Data Fields (Rome — Main Wedding)
* Individual per-event RSVP switches:
  * Event 1: Ciampini Welcome Dinner (Yes / No) *(Only for 3-Day guests)*
  * Event 2: Vatican Blessing & Villa Aurelia Gala (Yes / No)
  * Event 3: Hassler Farewell Brunch (Yes / No) *(Only for 2-Day & 3-Day guests)*
* `guestName` / `party_size` (1 or 2)
* `guestDiet`: Dietary restrictions, allergies, and personal message

### Backend Integration
* **Primary Database:** Google Sheets Web App Endpoint
* **Instant Email Notification:** FormSubmit endpoint dispatching formatted HTML tables directly to `elia.innamorati@gmail.com`
* **Offline / Local Backup:** `localStorage` (`wedding_rsvps`)
